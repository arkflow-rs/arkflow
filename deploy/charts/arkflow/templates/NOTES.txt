{{- else if eq .Values.mode "agent" }}

Agent node identity defaults to the pod name (ARKFLOW_NODE_ID from the
downward API) when your config does not set health_check.node_id.
Supply the registration credential as an env Secret (and enable persistence or
set ARKFLOW_NODE_CREDENTIAL_FILE so enrolled per-node `arkn_` credentials
survive pod restarts):

    env:
      - name: ARKFLOW_NODE_TOKEN
        valueFrom:
          secretKeyRef:
            name: <your-secret>
            key: node_token
