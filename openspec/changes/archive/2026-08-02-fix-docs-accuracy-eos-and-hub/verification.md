# Verification

Evidence that the `documentation-accuracy` spec requirements hold after this
change.

## Truth source: registered components

Captured from `./target/debug/arkflow components list` (reads the same
`register_*_builder` registry the release binary exposes):

- **Inputs (13):** file, generate, http, kafka, memory, modbus, mqtt,
  multiple_inputs, nats, pulsar, redis, sql, websocket
- **Processors (8 raw / 6 logical):** arrow_to_json, arrow_to_protobuf, batch,
  json_to_arrow, protobuf_to_arrow, python, sql, vrl
- **Outputs (10):** drop, http, influxdb, kafka, mqtt, nats, pulsar, redis,
  sql, stdout
- **Buffers (4):** memory, session_window, sliding_window, tumbling_window
  (`join` is a sub-configuration of the window buffers — the CLI describes
  session/tumbling windows as "Supports SQL joins across sources", and there is
  no registered `join` buffer type)
- **Codecs (4):** debezium_json, json, protobuf, schema_registry
