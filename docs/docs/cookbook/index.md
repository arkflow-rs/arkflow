# Cookbook

Practical, end-to-end recipes you can copy and adapt. Each recipe is a single
YAML config plus an explanation, and most map to a ready-to-run file under
`examples/` in the repository.

See [Exactly-once Kafka](./eos-kafka.md), [Debezium CDC](./debezium-cdc.md),
[log aggregation](./log-aggregation.md), [IoT ingestion](./iot-ingestion.md),
[stream-table enrichment](./stream-table-enrichment.md), and [Schema
Registry](./schema-registry.md).
