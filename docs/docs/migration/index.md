# Migration

Already using another tool? These guides map familiar concepts onto ArkFlow
and show how to translate a typical config.

ArkFlow's niche is a **single-binary, config-driven, columnar-SQL** stream
processor with production-grade reliability (input WAL, at-least-once by
default, opt-in exactly-once). It is lighter than distributed stateful
engines and more durable than stateless routers — see
[Why ArkFlow](../introduction/intro.md) for the positioning.

Read the guides for [Benthos/Bento](./from-benthos.md), [Vector](./from-vector.md),
[Flink](./from-flink.md), and [RisingWave](./from-risingwave.md).
