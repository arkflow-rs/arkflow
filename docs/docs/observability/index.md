# Observability

ArkFlow ships the building blocks needed to run it reliably in production:
an HTTP health server, structured logging, and Prometheus metrics. This
section documents how to observe a running engine.

Read the [health checks](./health-checks.md), [metrics](./metrics.md),
[tracing](./tracing.md), and [logging](./logging.md) guides. Deployment details
are in [Operations](../operations/control-plane/1-overview.md).
