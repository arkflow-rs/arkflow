# Logo 使用指南

![ArkFlow 标志](pathname:///docs/logo.svg)

ArkFlow Logo 是项目身份的象征。这些准则用于保持其使用方式的一致性。使用本 Logo 即表示你同意这些准则。

## TL;DR

- **允许** —— 用于链接或指代 ArkFlow 项目,出现在教程/文章/演讲中,以及表明你的项目基于 ArkFlow 构建。
- **不允许** —— 修改 Logo、将其用作*你自己的*主要品牌、暗示官方背书、将其用于付费周边商品,或在负面语境中使用。
- **先问再做** —— 任何商业用途、正式合作伙伴关系的声明,或此处未涵盖的其他用途。

## 权利

ArkFlow 名称与 Logo 是 ArkFlow 项目团队的商标,团队保留所有相关权利。只要你遵循这些准则,我们就授予使用这些标志的许可。该许可是非排他性的,且可能被撤回。

## 允许的使用

- 在你的网站、博客或社交媒体上,用于链接到 https://arkflow-rs.com/。
- 在介绍、评测、教程、新闻或涉及 ArkFlow 的演讲中使用,前提是不得暗示获得官方背书。
- 在你基于 ArkFlow 构建的开源项目的非商业材料中,用于表明这一关联(不得作为你项目的主 Logo)。
- 用于展示你对 ArkFlow 的贡献或使用。
- 在社区组织的非商业 ArkFlow 活动与聚会中使用。

## 禁止的使用

除非事先获得书面许可:

- **不要修改 Logo** —— 不得更改颜色、比例、字体或元素;不得添加文字或图形。请始终使用官方文件。
- **不要将其用作你自己的主要品牌**标识,用于产品、服务、公司、域名或账号。
- **不要暗示官方背书**或对你产品与活动的赞助。
- **不要将其用于商业产品或付费服务**(例如待售周边商品)。
- **不要在负面、误导性、低俗、非法或有争议的**语境中使用。
- **不要将其**(或近似标志)注册为你自己的商标。

## 视觉规范

- 从 ArkFlow 官方渠道获取最新的官方文件(SVG/PNG)。
- 使用官方配色;如需在特殊背景上使用反色/单色变体,请向我们咨询。
- 在 Logo 周围保留足够的留白空间。
- 不要拉伸、压缩、旋转或倾斜 Logo,也不要添加描边/阴影/渐变。
