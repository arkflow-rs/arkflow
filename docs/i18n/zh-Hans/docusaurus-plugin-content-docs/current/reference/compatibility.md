# 兼容性与版本策略

未带版本的文档描述当前开发主线。带版本的文档是发布快照,可能不包含之后引入的组件。

## 阅读版本敏感的页面

当某个组件、配置键、API 端点或投递保证与版本相关时,请使用版本下拉框并核对该版本的发布说明。只出现在 current 树中的特性,不得假设它存在于更早的快照中。

## 维护兼容性说明

当行为发生变化、配置键被重命名或端点被弃用时,请添加兼容性说明。在路由迁移正式宣布之前,保留旧路由或迁移占位页;路径变更请记录在[路由迁移映射](/zh-Hans/docs/migration/routes)中。
